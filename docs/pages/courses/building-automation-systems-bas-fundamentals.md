## Overview

- Building Automation Systems (BAS) are the control layer behind HVAC, lighting, and power monitoring in modern facilities — and increasingly overlap with the BMS and DCIM platforms used in data centers
- This course covers BAS architecture, sensor and controller basics, and how automation logic actually gets built and tuned
- You'll leave able to read a points list, understand a control sequence, and troubleshoot the integration issues that come up when BAS meets facility-specific monitoring
